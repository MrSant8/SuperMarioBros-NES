# Super Mario Bros - NES

## Description of the Game
Super Mario Bros is a plataform video game desenvoluped by [Nintendo](https://es.wikipedia.org/wiki/Nintendo) in 1985. In it, Mario and his brother Lugi have to rescue Princess Peach, who has been kidnapped by Bowser, the Koopas' king. 
To do so, they must journey through eight worlds filled with enemies, obstacles, and hidden shortcuts. Each level has different enemies, you can find coins, teleportation zones "_Warp Zones_" and the flagpole at the end, where the higher you jump the more points you earn.
Players can collect ítems to aid them in their mission: the Super Mushroom increases Mario's size and durability, the Fire Flower allows him to throw fireballs, and the Starman grants temporary invincibility.Throughout the game, players face a impostor Bowser in each castle before reaching the final showdown with Bowser.
After completing the game, players can restart it to experience an increase in difficulty, featuring faster enemies and level changes, providing a more difficult gameplay experience.

## Controls

*Super Mario Bros.* can be played with either a keyboard or a gamepad. The basic controls allow the player to perform actions like moving, jumping, and using power-ups:

### Keyboard Controls (PC):
- **Arrow Keys:**
  - **Left/Right Arrow:** Move Mario left or right.
  - **Down Arrow:** Crouch. Useful for avoiding low-hanging obstacles and enemies.
  - **Up Arrow:** Enter pipes or climb certain areas.

- **Spacebar:** 
  - **Jump:** Press to make Mario jump. Hold longer to jump higher.

- **SHIFT Key (or equivalent):**
  - **Run (if held down):** Makes Mario run faster. This is useful for jumping longer distances and defeating enemies.

- **Left Control Key (or equivalent):**
  - **Fire (if powered up):** Shoot fireballs when Mario has the Fire Flower.

- **P Key:** 
  - **Pause:** Pauses the game.

- **Enter Key:** 
  - **Start Game or Resume:** Starts or unpauses the game.

### Gamepad Controls:
- **D-pad/Left Stick:** 
  - **Left/Right:** Move Mario left or right.
  - **Down:** Crouch.
  - **Up:** Enter pipes or climb platforms.

- **A Button:** 
  - **Jump:** Press to make Mario jump.

- **B Button (or X):** 
  - **Run (if held down):** Mario runs faster.

- **Y Button (or equivalent):** 
  - **Fire (if powered up):** Shoot fireballs.

- **Start Button:** 
  - **Start/Pause:** Start the game or pause the action.
